# AI log

Your own account of how AI was used in this project. You write it, not the
agent (see docs/hard-rules.md). Add one entry after each task you worked on
with an agent, while you still remember what happened.

Each entry answers four questions:

- Generated by AI: what the agent produced, by feature, what you asked for and
  which provider you used.
- Written by me: what you wrote or rewrote by hand, and why.
- Verified: how you checked it (read the diff, ran the app, ran the tests) and
  what you found wrong.
- Decided: the choices you made, with the reason, and the agent's proposals
  you refused.

Vague entries do not count. "I used AI and checked everything" answers none of
the four questions.

## Entry format

```
## YYYY-MM-DD: feature or task
- Generated by AI: ...
- Written by me: ...
- Verified: ...
- Decided: ...
```

## Example (delete it when you add your first entry)

## 2026-10-12: Login page
- Generated by AI: the login page, with Copilot, from docs/specs/login.md.
- Written by me: the error messages; a user would not have understood the agent's.
- Verified: ran the app. With an empty field the "Conectare" button stayed
  active; asked for a fix and checked again.
- Decided: refused the "Forgot password" link the agent proposed; the spec
  leaves it out for now.

## Entries

## 2026-10-22: Login page
- Generated by AI: A static login page using HTML, CSS, and JavaScript, plus updates to the login specification, decisions, and project state.
- Written by me: I approved the implementation plan and confirmed that the page should remain presentation-only, without real or simulated authentication.
- Verified: Checked the JavaScript syntax and file diagnostics; tested required fields, invalid email, and form submission in the browser. `bin\check.cmd` failed because `docs/architecture.md` is not indexed in `AGENTS.md`.
- Decided: Keep the page static and clearly state that authentication is not connected; do not send credentials or redirect. No libraries were added.
