# Login page

A client-side login page built with HTML, CSS, and JavaScript. It provides a
form-only interface and does not authenticate users or send credentials to a
server.

## Non-standard
- No framework, server, build step, or runtime dependencies.

## Structure
- Repository root: static application files (HTML, CSS, JavaScript)
- docs/: project guidance and feature specifications
- bin/: repository configuration check
